Unsere Regeln

    So ändert ihr Regeln und den Infotext
    1. Auf GitHub im Repository die Datei content/infos.json öffnen.
    2. Oben rechts auf den Stift (Edit) klicken.
    3. Einen neuen Eintrag nach diesem Muster einfügen. Mehrere Einträge werden mit Komma getrennt, alles steht zwischen [ und ].
    4. Commit changes klicken. Nach 1–2 Minuten ist es auf der Seite.
    {
  "text": "Unser Server für Freunde. Seit Oktober 2026.",
  "regeln": [
    "Kein Griefing.",
    "Nichts aus fremden Truhen nehmen.",
    "Farmen nicht dauerhaft laufen lassen."
  ]
}

    Hier steht alles zwischen { und }. Jede Regel in Anführungszeichen, mit Komma getrennt.
