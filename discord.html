Für Admins: Discord mit der Website verbinden
  1. In Discord: Rechtsklick auf den Servernamen → Servereinstellungen → Widget.
  2. Server-Widget aktivieren einschalten und die Server-ID kopieren.
  3. Darunter bei Einladungskanal einen Kanal wählen.
  4. Einen Einladungslink erstellen: Rechtsklick auf den Server → Leute einladen → Einladungslink bearbeiten → „Läuft ab: Nie“.
  5. Auf GitHub die Datei assets/app.js öffnen, Stift klicken und ganz oben bei discord den Link und die Server-ID eintragen. Commit changes.
