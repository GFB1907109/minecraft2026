So tragt ihr ein Event ein
  1. Auf GitHub im Repository die Datei content/events.json öffnen.
  2. Oben rechts auf den Stift (Edit) klicken.
  3. Einen neuen Eintrag nach diesem Muster einfügen. Mehrere Einträge werden mit Komma getrennt, alles steht zwischen [ und ].
  4. Commit changes klicken. Nach 1–2 Minuten ist es auf der Seite.
[
  {
    "titel": "End-Öffnung",
    "datum": "2026-11-06 20:00",
    "ort": "Spawn",
    "text": "Gemeinsam den Enderdrachen besiegen.",
    "wer": ["Ali", "Mehmet"]
  }
]

Datum immer als JJJJ-MM-TT hh:mm. ort, text und wer sind freiwillig.
