Projekte & Orte

Was wird gebaut, wo ist was?

Bauprojekte mit Status und das Koordinaten-Buch für Basen, Dörfer und Portale. Alles mit Koordinaten erscheint auch auf der Karte.

So tragt ihr ein Projekt oder einen Ort ein
  1. Auf GitHub im Repository die Datei content/projekte.json öffnen.
  2. Oben rechts auf den Stift (Edit) klicken.
  3. Einen neuen Eintrag nach diesem Muster einfügen. Mehrere Einträge werden mit Komma getrennt, alles steht zwischen [ und ].
  4. Commit changes klicken. Nach 1–2 Minuten ist es auf der Seite.
[
  {
    "name": "Fenerbahçe-Stadion",
    "typ": "projekt",
    "status": "im Bau",
    "von": ["Ali"],
    "x": 250, "y": 64, "z": -120,
    "dimension": "overworld",
    "bild": "content/galerie/stadion.jpg",
    "text": "1:1-Nachbau des Şükrü Saracoğlu."
  },
  {
    "name": "Nether-Portal Basis",
    "typ": "ort",
    "x": 30, "y": 70, "z": 12
  }
]

typ ist projekt oder ort. status ist geplant, im Bau oder fertig. dimension ist overworld, the_nether oder the_end. Alles außer name ist freiwillig.
