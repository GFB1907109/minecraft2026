So kommt ein Bild in die Galerie
  1. Auf GitHub im Repository die Datei content/galerie.json öffnen.
  2. Oben rechts auf den Stift (Edit) klicken.
  3. Einen neuen Eintrag nach diesem Muster einfügen. Mehrere Einträge werden mit Komma getrennt, alles steht zwischen [ und ].
  4. Commit changes klicken. Nach 1–2 Minuten ist es auf der Seite.
[
  {
    "bild": "content/galerie/stadion.jpg",
    "titel": "Fenerbahçe-Stadion",
    "von": "Ali",
    "datum": "29.10.2026"
  }
]

Vorher das Bild auf GitHub in den Ordner content/galerie hochladen (Add file → Upload files). Der Dateiname muss genau mit bild übereinstimmen.
